# Oracle → execute → verdict

1. **Oracle first** — expected result from spec, UI contract, or agreed acceptance.
2. **Execute** — only what the oracle needs; capture evidence.
3. **Verdict**
   - **Pass** — actual matches oracle; evidence attached
   - **Fail** — actual differs; expected vs actual + evidence
   - **Blocked** — cannot finish (auth, env, missing data, tooling); name the blocker

Honest Blocked beats a fake Pass.
